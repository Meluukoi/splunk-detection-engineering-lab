# Splunk Detection Engineering Lab

## Overview

This project focuses on detection engineering and threat hunting using Splunk Enterprise, Sysmon, and Windows Event Logs.

The goal is to develop, validate, and investigate security detections for common attacker techniques by leveraging Windows telemetry and Splunk search queries.

---

## Objectives

- Create and validate security detections using Splunk
- Investigate Sysmon process creation events
- Monitor DNS queries and network connections
- Detect suspicious PowerShell and command-line activity
- Analyze Windows authentication events
- Map detections to MITRE ATT&CK techniques

---

## Lab Environment

### Tools Used

## Detection Scenarios

### Process Creation Detection (Sysmon Event ID 1)

Detect and investigate newly created processes such as:

- cmd.exe
- powershell.exe
- notepad.exe

Status: Completed

---

### Network Connection Detection (Sysmon Event ID 3)

Monitor outbound network connections and investigate destination IP addresses and ports.

Status: Completed

---

### DNS Query Detection (Sysmon Event ID 22)

Monitor DNS activity generated by user and system processes.

Status: Completed

---

### Failed Logon Detection (Windows Event ID 4625)

Detect failed authentication attempts and investigate brute-force activity.

Status: Completed

---

### Successful Logon Detection (Windows Event ID 4624)

Investigate successful user authentication events.

Status: Planned

---

### Encoded PowerShell Detection

Detect PowerShell commands executed with encoded payloads.

Status: Planned
